# SHAHMAT

Movegen-correct chess lib. Fastest plus least-memory per platform. Docker-first production.

Phase 0 scaffold. Board and movegen land in Phase 1 and Phase 2. SPEC in docs/SPEC.md is source of truth.

Run `cargo test` for gates. Run `cargo run --release --example perft -- startpos 6` for the bulk gate from Phase 2 on.
